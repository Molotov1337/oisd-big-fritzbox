# OISD Big Splitter

Automatically splits the [OISD Big](https://oisd.nl/) DNS blocklist into four smaller files for devices with limited storage capacity.

The lists are updated automatically using GitHub Actions. DNS filtering remains local on the device using the downloaded lists.
